# 🏛️ معمارية منظومة الزمردة (System Architecture)

## 1. نظرة عامة (Overview)
منظومة متكاملة للتجارة الإلكترونية والتسويق الآلي الذكي لشركة **الزمردة كوزماتيكس** المتخصصة في التوريدات، المنظفات، المعطرات، والمناديل المبللة (براندات رونزا، يونو، وخدمة Private Label).

---

## 2. خريطة الملفات والوظائف (File Structure Map)

```text
zomoroda-ai-system/
├── server.js               # خادم Express الرئيسي، محرك الردود، والـ Webhooks
├── database.js             # الاتصال المركزي بقاعدة البيانات (WASM SQLite عبر sql.js مع توافقية تامة)
├── zomoroda_system.db      # ملف قاعدة بيانات SQLite المحفوظة
├── whatsapp_service.js     # محرك الواتساب، إدارة الجلسات، طابور الإرسال، والرد الفوري
├── email_service.js        # خدمة إرسال الإيميلات الاحترافية عبر SMTP
├── send_campaign.js        # منسق حملات الواتساب واستخراج الأرقام من ملفات Excel
├── master_agent.js         # مدير توجيه الرسائل الواردة وحساب أوقات التأخير
├── master_all_campaigns.js # التشغيل التلقائي لكافة الحملات عبر مختلف المنصات
├── platform_router.js      # توجيه الإرسال عبر المنصة المناسبة (WhatsApp, FB, IG, Telegram)
├── social_scraper_agent.js # وكيل استكشاف واستخراج جهات اتصال جديدة من السوشيال ميديا
├── affiliate_tree_agent.js # محرك شجرة العمولات للمندوبات والماميز وترقيات المشرفات
├── ads_manager_agent.js    # إدارة الحملات الترويجية ومحتوى السوشيال ميديا 24/7
├── products_config.js      # قاعدة بيانات المنتجات، الأسعار، وحساب الفواتير
├── messages_config.js      # مكتبة الرسائل التسويقية المجهزة حسب كل قطاع
├── target_categories.js    # تعريفات القطاعات المستهدفة والكلمات المفتاحية
├── sent_history.js         # مكتبة فحص ومنع التكرار خلال 30 يوماً
├── config.json             # ملف الإعدادات العامة للمنشأة (الهوية، المواعيد، الأرقام)
├── run.js / run_email.js   # سكربتات تشغيل مباشرة للحملات
└── specs/                  # مجلد المواصفات التفصيلية لتقليل استهلاك التوكنز
```

## 3. قاعدة البيانات وجداول النظام (Database Tables)

1. **`affiliates`**: المندوبات، أرقام الهواتف، المشرفة التابعة لها، عدد المبيعات، وإجمالي العمولات.
2. **`orders`**: الطلبيات المسجلة، اسم العميل، الهاتف، القطاع، المنصة، التفاصيل، الإجمالي، والحالة (`Pending`, `Confirmed`).
3. **`sent_history`**: سجل الإرسال لمنع التكرار (المعرف الفريد، المنصة، القطاع، تاريخ الإرسال).
4. **`customers`**: سجل العملاء الواردين، القناة، الفئة، مرحلة الفانل، وهل تم الترحيب بهم مسبقاً (`welcomed_before`).
5. **`campaign_state`**: تتبع مؤشر المعالجة للحملات الكبيرة لتفادي إعادة الإرسال من البداية عند إعادة التشغيل.
6. **`manager_logs`**: سجل الإجراءات الإدارية.
7. **`monthly_offers`**: العروض الشهرية والخصومات لكل قطاع.
8. **`scheduled_posts`**: المنشورات المجدولة للنشر التلقائي.

## 4. نقاط الدخول والتشغيل (Execution Entrypoints)

- **تشغيل الخادم الشامل**: `npm start` أو `node server.js`
- **تشغيل حملة واتساب (Excel)**: `node run.js`
- **تشغيل حملة إيميل للفنادق**: `node run_email.js`
- **التشغيل الآلي المستقل لكافة الحملات**: `node master_all_campaigns.js`
- **إدارة العمليات عبر PM2**: `pm2 start ecosystem.config.js`
